GradeBook Pro — Teacher Edition V5 Upgrade

This upgrade preserves the colleague/teacher edition's customizable school, teacher, class names, and existing gradebook behavior while applying the newer professional report print styling.

Upgrade steps:
1. Export a JSON backup from the current app first.
2. Extract this ZIP.
3. Replace index.html and service-worker.js in your GitHub repository root with these files.
4. Commit/push the changes and wait for GitHub Pages to deploy.
5. Open the app and hard-refresh (Ctrl+Shift+R).

Student marks remain in each teacher's local browser storage. This update does not merge or upload student records.
For best PDF report colors in Chrome, enable Background graphics in the print dialog.
